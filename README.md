## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shopnil2001/lalmai-apk.git
   cd lalmai-apk
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npx expo start
   ```
